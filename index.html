Hatalar ve Çözüm Paneli

Hata: "404 File Not Found / Sayfa Bulunamadı"

GitHub Pages üzerinde `index.html` dosyasının adı yanlış veya kök dizinde (ana klasörde) olmadığında bu hata alınır. Dosya adının küçük harflerle `index.html` olduğundan emin olun.

Hata: "Invalid method declaration; return type required"

Plugin kodlarında `onEnable()` metodunun başında `void` ifadesi unutulduğunda derleme hatası verir. Metodu `public void onEnable()` olarak güncelleyin.
