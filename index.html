Hatalar ve Çözüm Paneli

Hata: "Bu siteye ulaşılamıyor / DNS_PROBE_FINISHED_NXDOMAIN"

https://voxelsculptor.mcpl.com adresine girmeye çalıştığınızda bu hatayı alıyorsanız, DNS yönlendirmesi henüz tamamlanmamış veya eksiktir.

  • CNAME Kontrolü: DNS sağlayıcınızda voxelsculptor kaydının Playergameplay142.github.io hedefine yönlendiğinden emin olun.
  • DNS Temizleme: Windows Komut İstemi (CMD) ekranında ipconfig /flushdns komutunu çalıştırın.
  • Yayılma Süresi: Yeni eklenen CNAME kayıtlarının aktif olması 15 dakika ile 24 saat arasında sürebilir.

Hata: "Invalid method declaration; return type required" (Derleme Hatası)

Java sınıflarındaki metod tanımlarında dönüş tipi eksik olduğunda oluşur. `onEnable()` metodunun başına `void` eklenerek çözülür.
